Workflow

  1. User registers and logs in
  2. Add money to eWallet
  3. Buy eTicket or apply for Toll Pass
  4. Admin approves pass and generates QR code
  5. Toll gate scans QR and verifies pass
  6. User views transaction history and renews pass

Note: This is a standalone HTML demo. QR generation, payments, scanning and notifications are simulated. No database is used, so data resets after refresh.
