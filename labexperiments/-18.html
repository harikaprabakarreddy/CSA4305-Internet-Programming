Workflow

  1. Farmer registers and lists products
  2. Public user registers and verifies OTP
  3. Search and view products
  4. Add items to cart
  5. Place order using wallet/payment (Demo)
  6. Farmer updates shipping and order status
  7. User tracks shipment and order history

Note: This is a standalone single HTML demonstration. OTP verification, payments, wallet, image uploads and shipping updates are simulated. No database is used, so all data resets after refresh.
