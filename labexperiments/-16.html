📋 ComplainEase - Online Complaint Management System

User Features

  • Register & Login
  • Post Complaint
  • Select Complaint Category
  • Upload Supporting Documents (Demo)
  • Mark Location using Google Maps (Demo)
  • Track Complaint Status
  • Complaint History
  • Receive Email/SMS Updates (Demo)
  • Provide Feedback
  • View Admin Contact Details
  • Browse Common Issues & Solutions

Officer Features

  • Officer Registration & Login
  • View Assigned Complaints
  • Update Complaint Status
  • Upload Proof of Work (Demo)
  • Respond to User Queries

Admin Features

  • Generate Officer ID & Password
  • Create/Delete User & Officer Accounts
  • View All Accounts
  • Change Passwords
  • Hide/Enable Features
  • Manage Complaint Information
  • Access All Officer Accounts
  • Complaint Resolution Dashboard

Workflow

  1. User registers and logs in
  2. Posts complaint with category, description and location
  3. Officer reviews complaint and updates status
  4. User tracks progress and receives notifications
  5. Admin manages accounts and complaint system

Note: This is a standalone single HTML demonstration. Google Maps, uploads, email/SMS notifications and database operations are simulated. Data resets after page refresh.
